# 30 Days of Streamlit AI

## Overview
A 30-day challenge building AI-powered applications with Streamlit. The app serves as a hub to explore each day's project.

## Project Architecture
- **Language**: Python 3.11
- **Framework**: Streamlit
- **Entry point**: `main.py`
- **Config**: `.streamlit/config.toml` (server on 0.0.0.0:5000, CORS/XSRF disabled for Replit proxy)

## Key Files
- `main.py` - Main Streamlit application
- `.streamlit/config.toml` - Streamlit server configuration
- `pyproject.toml` - Python dependencies

## Running
The app runs via `streamlit run main.py` on port 5000.
